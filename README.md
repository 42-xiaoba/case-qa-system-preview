# 智能案例问答系统（案例智答）

> 把案例原文、团队分析报告和 20 余篇学术文献一并"读进肚子"的 AI 问答助手——有问必答、句句标出处、数据不打诳语。
>
> 本项目为**清华大学智能社会治理公共政策案例分析大赛**而建，服务于备赛与答辩场景。

本 README 分为两部分：

- **第一部分 · 项目介绍**：帮助您在 5 分钟内了解系统的定位、功能与用法；
- **第二部分 · 本地使用教程**：手把手带你在自己的电脑上把系统跑起来（全程可零成本完成）；不熟悉命令行？直接看[第八节&#34;让豆包帮你完成&#34;](#八零动手方案让豆包帮你完成)，把部署交给豆包电脑版。

# 第一部分 · 项目介绍

## 一、项目定位

备赛时手头的资料又多又杂：案例原文、《案例分析报告一稿》、选题报告、20 多篇基层治理领域的学术文献……想找一个数据、核对一处观点，往往要在几十个 PDF 里来回翻。

这个系统做的事情很简单：**让 AI 提前"读完并记住"所有资料，然后像一位随叫随到、随身带着全部资料的队友一样回答你的问题。**

它对你有三个承诺：

| 承诺                     | 具体表现                                                                                               |
| ------------------------ | ------------------------------------------------------------------------------------------------------ |
| **答案有出处**     | 每个论断都标注来源：（一稿·章节名）、（作者，年份）、《文献名》、（案例文本·部分名），可直接回查原文 |
| **不知道就承认**   | 资料里没有的内容，它会明确说"现有资料未涉及"，绝不现场编造                                             |
| **关键数据零篡改** | 报表压减 50%、覆盖 11 个街道 72 个社区等核心数字被写进"铁律"，原样引用不许改动                         |

> 小科普：系统采用 **RAG（检索增强生成）** 技术——AI 回答前会先在本地知识库里"查资料"，把最相关的段落找出来再作答，而不是凭记忆自由发挥。这就像开卷考试：允许翻书，但只能抄书上有的。

## 二、功能一览

### 🤖 智能问答（核心功能）

在底部输入框输入问题即可。回答支持**逐字流式输出**（打字机效果），并自动按"一稿 > 案例原文 > 文献汇编"的可信度优先级组织内容。

可以这样问：

```
这个案例的研究意义是什么？
交易成本理论如何应用到"报表通"案例中？
就业帮扶链取得了什么成效？
一稿的分析框架是怎么搭建的？
范炜烽那篇文献对"数字悬浮"的解释是什么？
```

### 🔗 追问卡片（延伸提问）

每次回答完成后，下方会自动出现两张可点击的小卡片：

- **🔗 相关延伸**：顺着本次回答继续深挖的好问题
- **🌱 新话题**：同一主题下换个角度的新问题

点击卡片，问题自动填入输入框，回车即问——不知道下一问什么的"选择困难症"直接治愈。

### 🖼️ 图片识别问答

案例里的图表、流程图、政策截图看不懂？点左侧栏「🖼️ 添加图片」上传（PNG/JPG/WebP/GIF，一次一张），再用一句话描述你想问什么，视觉模型会结合图片内容和案例知识一起回答。未配置视觉密钥时此功能自动隐藏，不影响其他功能。

### 📄 PDF 对照阅读

右侧栏完整展示《案例报告》PDF，与左侧对话独立滚动、互不干扰：

| 操作         | 效果                       |
| ------------ | -------------------------- |
| 鼠标滚轮     | 上下翻页                   |
| ➕ / ➖ 按钮 | 放大 / 缩小（0.5x ~ 3.0x） |
| Shift + 滚轮 | 横向滚动放大后的页面       |

一边问"报表压减率是多少"，一边在右栏翻到对应页核对，答辩前自检特别好用。

### 💬 多轮对话记忆

连续追问时，AI 记得前面聊过什么（最近 6 轮原样保留；聊得再长，更早的内容会被自动压缩成摘要带上，不会"聊着聊着就失忆"）。左侧栏「🗑️ 清空对话」可一键重新开始。

### 🛟 多模型自动切换（稳定性的秘密）

系统同时接入多家大模型服务并按优先级排队值守，主力模型高峰期卡顿时，系统会在几秒内自动换下一位上场——**你什么都不用做，也不会察觉切换发生过**。完整的模型队列、免费政策与额度详见[第二部分·第四节](#四可用模型概览与免费政策)。

## 三、怎么用（界面速览）

| 你想做什么            | 操作                                                  |
| --------------------- | ----------------------------------------------------- |
| 提一个问题            | 在底部输入框输入后回车，回答逐字流式输出              |
| 继续深挖 / 换角度追问 | 点击回答下方的「🔗 相关延伸」或「🌱 新话题」卡片      |
| 问一张图表 / 政策截图 | 左侧栏「🖼️ 添加图片」上传，再用一句话描述你想问什么 |
| 对照原文核对数据      | 在右侧栏翻阅《案例报告》PDF（滚轮翻页，➕ ➖ 缩放）   |
| 重新开始一轮对话      | 左侧栏「🗑️ 清空对话」                               |

> ⏱️ 正常情况下首字约 8 秒内出现，整段回答约 15 秒完成；若某家服务商临时拥堵，自动切换会带来几秒额外等待，属正常现象。
>
> 📱 页面对手机屏幕做了完整适配，手机浏览器访问同样可用，适合答辩现场演示。

## 五、API 密钥获取教程

### 5.1 智谱 BigModel（必办 · 约 1 分钟）

1. 打开 [open.bigmodel.cn](https://open.bigmodel.cn)，手机号注册并登录；
2. 点击右上角进入「控制台」；
3. 左侧菜单找到「API Keys」（项目管理 → API Keys）；
4. 点「新建 API Key」，复制保存——这就是 `GLM_API_KEY`。

> 新用户注册即赠 2000 万 tokens；`glm-4.7-flash` 与 `glm-4.6v-flash` 两个免费模型不消耗赠送额度。

### 5.2 商汤日日新 SenseNova（强烈推荐 · 约 2 分钟）

1. 打开 [platform.sensenova.cn](https://platform.sensenova.cn)，注册并登录；
2. 在控制台找到 **Token Plan**，点「立即开始」开通（公测期完全免费，无需绑定银行卡）；
3. 进入「密钥管理」→ 创建密钥 → 复制保存——这就是 `SENSENOVA_API_KEY`；
4. 同一账号最多可创建 20 把 Key，可按需多建几把轮换使用。

> Token Plan 的调用端点为 `https://token.sensenova.cn/v1`（OpenAI 兼容格式），本项目已内置该地址，无需任何额外配置。

### 5.3 OpenRouter（可选 · 约 1 分钟）

1. 打开 [openrouter.ai](https://openrouter.ai)，用 Google / GitHub 账号直接登录；
2. 右上角头像 → 「Keys」→「Create Key」；
3. 复制 `sk-or-` 开头的密钥保存。

> 免费账户每天可调用 `:free` 模型 50 次；如需更多，可在账户里一次性充值 $10（信用永久有效）解锁每天 1000 次。此 Key 仅为额外保险，不办不影响任何核心功能。

## 六、本地配置教程

### 6.1 安装环境

需要 Python 3.10 或更高版本（[python.org](https://www.python.org/downloads/) 下载，安装时务必勾选 **"Add Python to PATH"**）。

### 6.2 获取代码并安装依赖

```bash
git clone https://github.com/42-xiaoba/case-qa-system-preview.git
cd case-qa-system-preview
# 国内网络不畅时可改用 Gitee 镜像：
# git clone https://gitee.com/sky-42-xiaoba/case-qa-system.git

pip install -r requirements.txt
```

### 6.3 创建 `.env` 密钥文件

在项目根目录新建文本文档并改名为 `.env`，按需填入上一步申请的密钥：

| 变量名                 | 必要性   | 作用                                     | 来源平台                         |
| ---------------------- | -------- | ---------------------------------------- | -------------------------------- |
| `GLM_API_KEY`        | ✅ 必填  | 备用文本模型 + 全链路兜底保障            | 智谱                             |
| `SENSENOVA_API_KEY`  | 强烈推荐 | **主力回答模型**，额度充足、响应快 | 商汤                             |
| `GLM_V_API_KEY`      | 可选     | 图片识别功能（不配则图片入口自动隐藏）   | 智谱（可与`GLM_API_KEY` 相同） |
| `OPENROUTER_API_KEY` | 可选     | 额外一道保险                             | OpenRouter                       |

填写格式（一行一个）：

```ini
GLM_API_KEY=你的智谱密钥
SENSENOVA_API_KEY=你的商汤密钥
GLM_V_API_KEY=你的视觉密钥
OPENROUTER_API_KEY=你的OpenRouter密钥
```

> 🔑 **多 Key 轮换**：如果手里有多把同平台 Key，可按 `GLM_API_KEY_2`、`GLM_API_KEY_3`、`SENSENOVA_API_KEY_2`…… 的命名追加到 `.env`，系统会自动轮流使用、分摊限额（商汤一个账号能建 20 把 Key，等于把 1500 次/5 小时的额度放大数倍）。
>
> 🔒 `.env` 已被 `.gitignore` 排除，**不会被上传到 Git 仓库**，放心填写；也请勿把密钥发给他人。只有 `GLM_API_KEY` 是硬性必需——哪怕只配这一把钥匙，全链路也能跑通。

## 七、启动方法

本地使用推荐开两个终端：

```bash
# 终端 1：启动后端服务（提供检索、记忆等能力，固定走 8000 端口）
python app.py

# 终端 2：启动前端界面
streamlit run ui.py
```

浏览器访问 **http://localhost:8501** 即可开始提问。

<details>
<summary><b>直连模式</b>（不想开后端？）</summary>

只执行 `streamlit run ui.py` 也可以用——前端检测不到后端时会自动改为直接调用模型 API，问答功能完整可用（适合云端部署场景）。

</details>

<details>
<summary><b>局域网 / 手机访问</b></summary>

```bash
streamlit run ui.py --server.address 0.0.0.0
```

同一 Wi-Fi 下的任何设备（包括手机）访问 `http://<你的电脑IP>:8501` 即可。界面针对手机屏幕做了完整适配。

</details>

<details>
<summary><b>部署到云端</b></summary>

推送到 GitHub 后，登录 [Streamlit Cloud](https://streamlit.io/cloud) → New app → Main file path 填 `ui.py` → 在 Secrets 页面按上面的变量名添加密钥 → Deploy。`.env` 不上传没关系，Secrets 就是它的云端替身。

</details>

## 九、项目结构

```
├── app.py                # FastAPI 后端：检索、记忆、流式接口、PDF 服务
├── ui.py                 # Streamlit 前端主入口（界面与交互都在这）
├── config.yaml           # ⭐ 全局配置：提示词三层 / 模型参数 / 降级链 / 检索预算
├── core/
│   ├── router.py         # 问题路由：判断该走文本回答还是图片识别
│   ├── knowledge_base.py # 本地知识库：关键词检索 + 加权重排
│   ├── pipeline.py       # 组装回答的输入：资料 + 历史 + 提示词
│   ├── memory.py         # 对话记忆：近期保留 + 超长滚动摘要
│   ├── llm_client.py     # 多模型调用封装 + 自动降级切换
│   ├── prompt_manager.py # 三层提示词组装 + 视觉消息构建
│   └── config.py         # 配置加载（读取 config.yaml + .env）
├── kb/                   # ⭐ 已建好的知识库（克隆即用，无需重建）
│   ├── chunks.json       # 全部资料切成的知识块
│   ├── tier0_card.md     # 常备知识卡（每问必带的核心事实）
│   ├── synonyms.json     # 检索同义词扩展表
│   └── user_dict.txt     # jieba 自定义词典
├── resources/            # 参考文献 PDF + 文献要点汇编
├── scripts/              # 知识库构建 / 质量评测工具（日常不用管）
├── case.txt              # 案例原文
├── case_report.pdf       # 右栏展示的案例报告 PDF
├── requirements.txt      # 依赖清单
└── .env                  # 你的密钥（自行创建，不上传 Git）
```
